## Featured Projects

### 1. VendorVet — Software Supply Chain Security

**Category:** Security Engineering | Software Supply Chain Security | AI-assisted Security Analysis

A software supply chain intelligence system that automatically decomposes binary files and software packages into structured Software Bill of Materials (SBOMs), maps their underlying dependency trees, and continuously evaluates them against global vulnerability data feeds to summarize active threats.

**Key areas:**
- Binary decomposition and software security analysis.
- Static-AI hybrid reachability analysis.
- Risk prioritisation based on proximity to sensitive data.
- Plain-English security alerts and automated containment capabilities.

### 3. Secure Multi-threaded HTTP Server

**Category:** Security Engineering | Network Programming | Application Security

A Python-based multi-threaded HTTP server developed with an emphasis on concurrency, request handling and security hardening.

**Key areas:**
- Thread-pool architecture and concurrent request handling.
- Directory traversal protection through path normalisation.
- Content-Type validation.
- Host-header verification.
- Graceful degradation under concurrent load.
